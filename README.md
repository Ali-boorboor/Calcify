## Scripts 📄

```bash
 pn run dev
```

> pn (pnpm) will run `dev` script which will run your code on development phase and watch it.

```bash
 pn run build
```

> pn (pnpm) will run `build` script which will build your code for production phase.

```bash
 pn run preview
```

> pn (pnpm) will run `preview` script which will give you a preview of build version.

## Notes 📝

> Package manager of this project is `pnpm`.

> Bundler (build tool) of this project is `vite`.

| Directory         | Description                                                                     |
| :---------------- | :------------------------------------------------------------------------------ |
| `/public`         | **Static** files are located in here.                                           |
| `/src/components` | **Components** are located in here.                                             |
| `/src/constants`  | **Constants** files and datas that used for data-driven UI are located in here. |
| `/src/hooks`      | **Hooks** and reducers (states) and their logics are located in here.           |
| `/src/utils`      | **Utils** and functions that calculate and format datas are located in here.    |
